# XML Invoice Explorer

This XML invoice explorer is a 5 hour project built using React and Typescript. 
This also uses UBL-2.1.xml validation rules, picked directly from https://docs.oasis-open.org/ubl/ 
Supports all the UBL related XML rules. UAC, UBC.


This XML explorer is only for one document type i.e., Standard Tax Invoice. Does not support other document types for now.


#### This is a two step process:

  1. Copy paste your XML or drag and drop the file onto the webpage
  2. Get a detailed breakdown of the XML document in the webpage UI.
